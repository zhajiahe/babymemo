# 网页管理、完整导出与离线使用

网页和微信都是家庭记录的完整操作入口。网页没有独立 AI 聊天或医学诊断。

## 记录与宝宝资料

- 成长记录与成长瞬间：新增、日期和关键词查询、按记录编辑、移入30天回收站及恢复。
- 相册：日期/类型查询、原件预览、修改拍摄日期、下载和移入回收站。已关联的瞬间照片/视频可直接预览。
- 宝宝：昵称、生日、可选出生时间、性别、时区、过敏信息、档案备注；256px私有JPEG头像，可更换或移除。
- 移出宝宝属于可恢复的归档，保留全部资料与媒体，不会把关联记录级联删除；至少保留一位常用宝宝。
- 首页近期瞬间独立读取第一页，历史分页与筛选不会改变首页内容。页面重新获得焦点时更新家庭数据。

编辑使用 `updated_at` 版本，遇到其他设备的更新会拒绝覆盖。草稿保留，用户可核对服务器版本后再保存。网页请求用稳定编号；更新和回执在同一D1事务，丢失响应后重试不会重复提交或重放旧修改。

## 完整家庭导出

设置页的「下载完整家庭档案 ZIP」包含：

| 路径 | 内容 |
| --- | --- |
| `records.json` | 家庭名称、完整宝宝资料（含出生时间和归档状态）、成长记录、瞬间、媒体元数据、回收站记录、瞬间与媒体关联 |
| `media/` | 照片和视频原件，按宝宝分目录 |
| `avatars/` | 当前宝宝头像，含已移出宝宝的头像 |
| `thumbnails/` | 已存在的私有派生图 |
| `manifest.json` | 归档文件路径、类型、大小的对应清单（对象键保留在records.json元数据中） |
| `README.txt` | 归档说明 |

默认导出由浏览器逐个读取经过登录验证的原件，再通过本机下载通道流式生成ZIP，避免单次Worker的操作和CPU配额随整个相册增长。ZIP64支持超过4GiB的文件格式，原件顺序流式读取，CRC32用于归档字节校验。缺失或大小不一致的原件会报错；下载中途失败会中断归档，不会静默省略文件。未启用下载通道的浏览器回退到服务器流式ZIP接口；这个兼容入口仍受所部署Worker的执行与子请求配额约束。

数据库元数据在同一D1事务中读取，R2随后读取。导出期间尽量不要删除或更换媒体；数据库与对象存储不是跨服务原子快照。JSON单独下载不含原件。

这是用户资料导出，不含管理员登录哈希、OpenRouter Key、微信 Token或会话密钥。部署环境的灾备仍使用 [备份与恢复](BACKUP.md) 中的SQL/R2流程。

## 离线与本机存储

生产构建生成Service Worker外壳，首次在线访问完成缓存后可离线重新打开。成长记录、瞬间及宝宝资料草稿按宝宝隔离，保存在本机；关闭标签页不再删除草稿。

离线保存先写入IndexedDB，页面显示「待同步」，不会把本机保存说成已保存到服务器。联网且登录有效时，队列按顺序提交；重新打开页面也会继续。连续离线编辑使用前一项的实际回执版本，不会重新读取最新版本然后自动覆盖。照片/视频原文件可先存入本机，重新联网后自动上传，大文件继续使用8MiB分片。

同步遇到版本冲突或非法请求时停止并提示。用户可重试，或将记录内容取回草稿后移出队列、核对服务器记录再编辑。网络暂时失败保留任务；密码及第三方连接配置不加入队列。

离线能读取访问过、已缓存的页面数据。尚未缓存的历史页与筛选结果需要联网打开一次；不是自动下载整个云端相册。媒体预览中的「离线保存」可持久保存原件；浏览器的视频Range请求使用本机字节分段返回。

本机存储只在该浏览器/设备有效。主动退出清除私有缓存、队列与草稿；浏览器清理站点数据或存储空间不足仍可能移除数据。本机缓存不替代家庭档案导出或灾备。不要在公共设备上保留已登录的离线资料。

## 兼容与验证

新功能需要先应用增量迁移 `0016_web_management.sql`，再发布Worker。旧表和原件保留。

测试包含只读误选写工具、新旧日期角色、瞬间记录快捷判断、清理认领、ZIP标准读取器校验、网页版本冲突与请求重放；浏览器覆盖编辑、头像、首页分页及离线重开/同步。Chromium/Linux WebKit均不代表真实iPhone Safari验收。
