# 网页、离线与家庭导出

## 管理记录

在网页查看和编辑宝宝资料、成长数据、成长瞬间及相册。删除的记录可在 30 天回收站中恢复。如果另一台设备先修改了同一条记录，页面会提示冲突，不会悄悄覆盖。

## 导出资料

在「设置 → 下载完整家庭档案 ZIP」保存宝宝资料、成长记录、照片与视频原件、头像和已有封面。单独导出的 JSON 不包含媒体文件。

**家庭档案不包含管理员密码或部署密钥，也不能替代完整环境备份。** 恢复整套服务请阅读 [备份与恢复](BACKUP.md)。导出时尽量避免其他设备删除或更换媒体。

## 离线使用

已访问过并缓存的内容可以离线查看；照片和视频需要事先打开或明确保存，不能假设所有相册内容已下载到本机。

断网时，新建或编辑的记录会标记为「待同步」，重新联网并保持登录后再提交。发生内容冲突时会暂停，需先核对服务器记录。设备清理网站数据或存储空间不足可能造成未同步内容丢失；退出登录会清除本机私有缓存和队列。

离线数据仅保存在当前设备，请定期导出档案，不要将本机缓存作为唯一备份。
