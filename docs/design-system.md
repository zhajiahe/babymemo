# 设计规范 · Calm Editorial

定位：**家庭成长日记，而非仪表盘**。内容先于装饰，以真实照片、完整故事、日期和测量历史为主；无数据就显示空状态，不编造健康结论。

## 交互准则

- **相册**默认故事卡片，文字描述不截断，可切换紧凑照片墙；预览优先展示故事，日期、编辑、下载与回收站操作按需出现。
- **封面**照片与视频均可修复；视频可从播放画面截帧或上传 JPG/PNG/WebP 作封面。设置页的全部封面修复依赖已登录浏览器，关闭页面后不会在云端自行继续。
- **导航**移动端：首页、相册、成长、设置；成长瞬间从首页进入。宝宝只在「设置 → 宝宝资料」切换，家庭名称始终可见。
- **移动与无障碍**最小 44px 触控目标、清晰焦点、safe area、软键盘避让、键盘左右键/滑动切图、原生视频控件和 reduced motion。
- **真实状态**所有上传、离线同步、错误、重试和空列表都明确反馈；已上传原件不等于封面生成成功。

## 视觉变量

| 用途 | CSS Token | 值 |
| --- | --- | --- |
| 页面 | `--bm-page` | `#F7FAFD` |
| 内容 | `--bm-surface` | `#FFFFFF` |
| 正文 | `--bm-ink` | `#243448` |
| 次要文字 | `--bm-muted` | `#586D80` |
| 强调 | `--bm-brand` | `#2165A8` |
| 描边 | `--bm-border` | `#DDE6EF` |

使用系统字体，不添加大型渐变欢迎卡、无意义统计卡或泛化营销文案。`src/styles.css` 放基础布局与表单，`src/editorial.css` 放首页、相册和移动视觉；避免在末尾堆叠样式覆盖。唯一品牌 SVG 母版位于 `public/brand/icon-source.svg`，通过 `scripts/build-brand-assets.mjs` 生成图标。

UI 修改应覆盖 320/375/390/768/1280px、空相册和视频、断网、上传、预览与输入法；Chromium/Linux WebKit 不等于真实 iPhone Safari/HEIC/MOV 验收。
