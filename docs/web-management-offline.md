# 网页、家庭导出与离线

网页支持宝宝资料、成长记录、成长瞬间和相册的增删改查、30 天回收站与恢复。更改采用 `updated_at` 版本校验；冲突时保留草稿并提示，不能静默覆盖其他设备的修改。

## 导出

「设置 → 下载完整家庭档案 ZIP」包含 `records.json`、`media/`、`avatars/`、`thumbnails/`、`manifest.json` 与说明文件；原件经登录授权读取，浏览器优先流式生成 ZIP64（大档案可超过 4 GiB）。单独 JSON 不含媒体原件；任一文件缺失或不匹配时导出会报错，不静默跳过。

数据库快照与 R2 读取**不是跨服务原子操作**，导出期间避免更改媒体。家庭 ZIP 不包含管理员哈希及部署凭据，也不是完整环境恢复方案；灾备见 [BACKUP](BACKUP.md)。

## 离线与同步

首次在线访问缓存应用外壳；访问过的页面和明确保存的媒体可离线读取，**不代表已下载所有云端相册**。草稿、待同步写入及原文件保存在本机 IndexedDB，并按宝宝隔离；页面标记「待同步」，重新联网/登录后有序重试。

冲突或不合法操作会停止队列并要求人工处理；连续修改依据前一次真实回执版本，不偷偷覆盖服务器最新记录。大文件可续传；设备空间不足或清除站点数据可能导致本机未同步内容丢失。登出清除私有缓存及队列，公共设备慎用离线模式。敏感密钥与连接配置不进入离线队列。

离线体验和导出完整性使用隔离本地 E2E 验证；真实手机后台、Safari 存储策略和生产恢复仍需单独验收。
