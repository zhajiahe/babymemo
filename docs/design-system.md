# BabyMemo 设计规范 · Calm Editorial

> 定位：家庭成长日记，而不是套用亲子配色的 SaaS Dashboard。

## 基本原则

- **内容先于装饰**：首页优先真实照片、历史成长数据和时间轴；相册默认展示照片，不使用假封面。无照片时提供明确空状态。
- **表达真实信息**：用宝宝名字和实际年龄作为页面标题，尽量删去“闪闪发光”等通用营销文案与无信息量英文小标题。
- **尊重历史**：成长曲线按实际测量时间绘制，数据不足就留空，不自动生成健康结论。
- **操作藏在需要的地方**：照片网格不展示标题或删除；媒体预览保留下载、修改拍摄日期和移入回收站。照片收藏功能已移除。上传与续传面板按需展开。
- **移动端优先**：底部导航只有首页、相册、成长和设置；成长瞬间从首页和桌面导航可进入。主要触控控件 ≥44px。iPhone 顶部家庭名称栏滚动时持续可见，Tab 保留图标和文字；再次点当前 Tab 回到顶部，成长瞬间作为首页二级页提供返回入口。表单输入时隐藏底部 Tab Bar 避开软键盘；照片预览可横向滑动、键盘左右方向键翻页和读屏播报，视频沿用原生播放控件。
- **情绪来自家庭内容**：不使用大型渐变欢迎卡、三色统计卡、装饰心形或星星。单一强调色即可。

## 视觉规范

| 用途 | Token / 色值 |
| --- | --- |
| 页面 | `--bm-page: #F7FAFD` |
| 内容 | `--bm-surface: #FFFFFF` |
| 正文 | `--bm-ink: #243448` |
| 次要文字 | `--bm-muted: #586D80` |
| 品牌强调 | `--bm-brand: #2165A8` |
| 轻描边 | `--bm-border: #DDE6EF` |

不引入网络字体，优先系统字体、苹方等回退字体。信息层级通过字重、字号和间距表达，不依赖彩色装饰卡片。

## 代码边界

- `src/styles.css` 仍提供布局基础、设置表单、上传、焦点、错误与空状态；其基础语义 tokens 已同步为品牌色。
- `src/editorial.css` 独立收敛首页、成长页、相册、导航、媒体预览及移动布局。后续新增样式应修改对应规则，不在样式表末尾反复叠加覆盖。
- `src/App.tsx` 加载真实私有媒体与成长曲线，界面不显示任何演示数据；空间名称在桌面侧栏与手机顶部持续可见。宝宝仅从设置页切换，切换时清空旧内容避免跨宝宝闪现。
- `src/features/album/Album.tsx` 保持分页和照片日期分组；只移动视觉控制，不改变上传/断点续传或元数据 API。
- `src/features/growth/RecordView.tsx` 优先呈现曲线、历史时间线，随后是新增表单。
- `src/components/MediaViewer.tsx` 承载移入回收站、下载和日期修改，保留原生 `dialog` 焦点管理。
- `public/brand/icon-source.svg` 为唯一可编辑矢量品牌母版（蓝色渐变、宝宝与成长日记）；图标主体刻意保持在 maskable 安全区域；`scripts/build-brand-assets.mjs` 在开发、单元测试和构建前生成 favicon、wordmark、Apple touch 图标及标准/maskable PWA 图标，杜绝图标版本不一致。图标允许原插画中的渐变，页面不增加大面积渐变装饰。

## 质量与上线检查

1. `npm run verify`、Worker E2E、Chromium/WebKit 浏览器检查通过。设计测试覆盖页面结构和 PWA 资源。
2. 320/375/390/768/1280 px 无溢出；Safari 输入不发生无意自动缩放；Safari 和主屏幕 PWA 的顶部栏、底部栏、全屏相册在刘海及 Home Indicator 处预留 safe area；焦点轮廓明显。
3. 空相册、有照片、含视频、上传、续传、删除、修改日期、分页和回收站流程均验证；照片预览加载/失败、滑动边界、键盘方向键、屏幕阅读器播报、软键盘不遮挡底栏也要检查。
4. 视觉类 PR 默认不改动 Worker、D1、R2、微信操作协议、正式数据或鉴权。涉及字段变更时遵循现行 D1 迁移流程，不复制历史 PR 的发布指令。
5. Chromium/WebKit 测试不等于真实 iPhone Safari 验证；HEIC/MOV/蜂窝网以及弱网下的上传仍需实机检查。
